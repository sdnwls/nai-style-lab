# NAI Style Lab

NovelAI 작가 태그 조합을 만들고, 둘 중 마음에 드는 쪽을 고르는 것만으로 내 취향의 그림체를 찾아 다듬는 앱입니다.

## 실행

`run.bat`을 더블클릭하면 창이 열립니다. 창을 닫으면 저장 후 자동으로 종료됩니다.
이미지 생성 중에 창을 닫으면 진행 중인 생성은 기다리지 않고 멈춥니다. 이미 NovelAI에 보낸 한 장의 결과는 받지 못하고 버려지며, 그때까지 만든 것은 저장됩니다.

- 데이터: `data/` (state.json, 실행할 때마다 남기는 직전 백업 state.json.bak, images/, api_key.txt, 썸네일 캐시 thumbs/)
- 오류 기록: `data/app.log`

### 버전과 업데이트

앱을 실행할 때마다 GitHub Releases에 새 버전이 있는지 한 번 확인하고, 있으면 사이드바에 알림이 뜹니다. 설정 → 데이터 → 업데이트에서 설치하면 새 버전을 받아 앱이 닫혔다가 새 버전으로 다시 열립니다.

- `data/` 폴더는 업데이트할 때 건드리지 않습니다.
- 파일 교체는 앱이 닫힌 뒤 전부 되거나 전혀 안 되거나 둘 중 하나입니다. 중간에 실패하면 이전 파일로 되돌리고 이전 버전으로 다시 엽니다.
- 받은 파일은 크기와 체크섬(GitHub가 알려 주는 SHA-256)을 확인한 뒤에만 설치합니다.
- 데이터 형식이 바뀌는 업데이트라면 새 버전이 처음 실행될 때 원래 파일을 `state.schemaN-날짜.json`으로 남기고 변환합니다. 더 새 버전이 저장한 데이터는 옛 버전이 열지 않습니다.
- 소스 폴더(`_dev`가 있는 폴더)에서는 확인만 하고 설치하지 않습니다.

## 워크플로

화면 위쪽의 단계 표시와 **지금 할 일** 버튼이 항상 다음 행동을 알려 줍니다.

| 단계 | 하는 일 | 화면 |
|---|---|---|
| ① 준비 | API 키 입력, 작가 등록, 무작위 조합 만들기 | 설정 · 작가 · 조합 만들기 |
| ② 순위 결정 | 새 조합은 기존 순위표 사이에서 이진 탐색으로 자리를 찾습니다. 배치 중에는 기존 조합의 Elo가 흔들리지 않습니다. | 대결 |
| ③ 진화 | 지금의 상위 30%(S·A) 조합들의 작가와 가중치를 섞고 바꿔 새 조합을 만들고, 대결로 상위 30% 사이 어디쯤인지 찾습니다. 그중 가장 낮은 조합에게도 지면 탈락, 이기면 살아남고 그 수만큼 기존 최하위가 제외됩니다. 전체 조합 수는 유지됩니다. | 진화 · 대결 |
| ④ 다듬기 | 고른 그림체의 작가는 그대로, 가중치만 바꾼 변형이 챔피언에게 도전합니다. 같은 시드로 그려 그림체 차이만 비교하고, 라운드마다 조정 폭이 ±0.3 → ±0.2 → ±0.1로 줄어듭니다. | 다듬기 · 대결 |
| ⑤ 완성 | 다른 시드 3개로 원본과 챔피언을 나란히 비교하고 확정하면 최종 태그가 복사됩니다. | 다듬기 |

### 대결의 자동 모드

대결 화면은 기본적으로 자동 모드입니다. 지금 필요한 대결을 우선순위대로 골라 줍니다.

1. 상위 30% 경계 동점 해소 (어느 모드에서든 가장 먼저, 일반 대결처럼 Elo에 반영)
2. 새 조합 자리 찾기
3. 진화 조합 평가 (만드는 중에는 이미 만들어진 조합의 자리 찾기만, 검증 대결은 다 만든 뒤)
4. 다듬기 챔피언 대결
5. 할 일이 없으면 일반 리그로 순위 결정

`전체 리그`와 `상위 30%` 모드는 순위만 더 다듬고 싶을 때 씁니다.

### 단축키

`←` / `→` (숫자 패드 `4` / `6`) 고르기 · `Enter` 비슷함(건너뛰기) · `Backspace` 되돌리기(여러 번 가능) · 휠 확대 · 드래그 이동 (그림체 목록·다듬기·자유 생성에서는 이미지 클릭으로 크게 보기). 원본은 이미지 옆 원본 열기 버튼으로 엽니다.
대결의 확대·이동은 양쪽 그림에 함께 적용되어 같은 부분을 나란히 비교할 수 있습니다. 두 그림이 다 뜨기 전에는 고를 수 없고, 키를 누르고 있어도 한 표만 들어갑니다.
그림체 목록과 작가 표에서는 클릭 선택(다시 클릭하면 해제), `Shift`/`Ctrl` 다중 선택, `Delete` 삭제, `Ctrl+A` 전체 선택, `Esc` 선택 해제.

### 그 밖의 기능

- **프롬프트 뷰어**: NovelAI로 만든 PNG(메타데이터가 남아 있는 원본)를 앱 창에 끌어다 놓으면 프롬프트·캐릭터·네거티브·설정을 보여 주고, 그림에 쓰인 작가(`artist:` 태그)를 한 번에 등록할 수 있습니다. 네거티브의 작가와 음수 가중치 작가는 등록하지 않습니다.
- **특정 조합 만들기**: 작가 · 조합 만들기에서 `1.2::artist:rurudo ::, 0.9::artist:shigure ui ::`처럼 적은 작가와 가중치 그대로 조합을 하나 만들어 그림체 목록에 넣습니다(조합 규칙은 적용하지 않음). 등록되지 않은 작가는 함께 등록합니다.

## 규칙

- **시드 하나로 모든 그림을 그립니다.** 설정의 시드가 비어 있으면 첫 생성 때 무작위로 정해 저장합니다.
- **NovelAI 웹에서 다시 뽑기**: 앱은 웹과 같은 설정(Variety+ 없음, 품질 태그·UC 프리셋 없음)으로 그립니다. 앱 그림을 웹에 끌어다 놓고 Import Metadata로 불러오면 같은 그림이 나옵니다. 웹은 불러온 캐릭터를 이미 있는 캐릭터 뒤에 더하므로, 불러오기 전에 웹의 캐릭터 칸을 비우고, 웹의 품질 태그·UC 프리셋은 None으로 두세요.
- **조합 규칙**(조합당 작가 수, 가중치 범위)은 작가 · 조합 만들기에서 바꾸며, 무작위 조합·진화 조합·다듬기 변형 모두에 적용됩니다. 예전 설정으로 만든 조합에서 가져온 값도 범위 안으로 맞춥니다.
- **진화 조합 만들기**: 상위 30% 조합 하나의 작가 1~3명 교체·삭제·추가(가중치 ±0.3), 상위 30% 조합 둘 섞기, 완전 무작위를 1/3씩. 부모는 순위가 높을수록 잘 뽑힙니다(1위가 꼴찌의 2배). 새로 뽑는 작가는 지금 상위 30%에 적게 쓰인 작가일수록, 그리고 작가 점수가 높을수록 잘 뽑힙니다(최고 점수 작가가 평균의 2배, 최저는 0.5배, 기록이 없는 작가는 평균). 진화 기록에 방식과 부모를 남깁니다.
- **투표가 모순될 때**(윗 순위는 이기고 아랫 순위에는 짐) 어긋나는 표가 가장 적은 자리로 배치하고, 합격선 근처는 검증 대결을 더 합니다.
- **탐색 종료 신호**: 2세대 연속으로 살아남은 진화 조합이 없으면 다듬기로 넘어가라고 안내합니다.
- **최종 확인**에서 챔피언이 원본 그대로면 원본만 다른 시드로 한 번씩 그립니다. 중간에 멈추면 라운드 결과 화면으로 돌아갑니다.
- **점수 단위**: Elo는 보통의 10배 단위(시작 10000점, K 320)로 정수만 씁니다. 1000점 단위에서 반올림 때문에 생기던 동점을 줄입니다. 예전 데이터는 처음 실행할 때 한 번 10배로 바뀝니다.
- **작가 점수**: 작가 표의 점수는 그 작가가 들어간 평가된 조합들의 Elo에서 작가의 몫을 떼어 낸 값입니다(평균 0, 가중치 1 기준). 함께 쓰인 작가의 영향과 가중치를 구분하고, 들어간 조합이 적으면 0에 가깝게 나옵니다.
- 대결에서 고르면 두 조합의 Elo가 어떻게 바뀌었는지 1초 동안 보여 준 뒤 다음 대결로 넘어갑니다(비슷함 등으로 그대로면 +0, 평가중인 조합은 평가중).
  **블라인드** 토글을 켜면 티어·Elo·전적·태그를 ???로 가리고 그림만 보고 고르며, 고른 뒤 그 1초 동안 모두 공개합니다.
- 탈락·제외된 조합은 지우지 않고 그림체 목록에 탈락 · 제외 표시로 남습니다. 부활, Elo 수정, 삭제, 전부 삭제가 가능합니다. 진화 평가·자리 찾기 중인 조합의 Elo를 고치면 그 순위표에도 바로 반영됩니다.
